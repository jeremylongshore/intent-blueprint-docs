# Template catalog

| Frame | Project brief, PRD | Market research, competitor analysis, personas, journeys, brainstorming |
| Decide | Architecture description, ADR, risk register | Frontend specification, security/privacy/AI annexes |
| Deliver | Stories, acceptance criteria, task plan | Process guide, requirements traceability matrix |
| Verify | Test plan, QA decision record | Usability study, control evidence register |
| Operate | Release plan, operational readiness | Metrics registry, runbooks, postmortem |
