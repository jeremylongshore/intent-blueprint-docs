# `@intentsolutions/blueprint`

Model-neutral project-document generation for people and automation. This package contains the Blueprint CLI, JavaScript API, MCP server, typed 22-document catalog, historical compatibility templates, and optional example packs.

```bash
npx --package @intentsolutions/blueprint blueprint --help
```

Default generation creates evidence-labeled drafts and never grants human approval. See the [main project](https://github.com/jeremylongshore/intent-blueprint-docs) for the 30-second workflow, documentation, and Apache-2.0 license.
