# Optional example packs

These packs are teaching aids, not project evidence. Blueprint never includes them in generated documents unless a person explicitly requests one.

Every pack is governed by the same three machine-readable rules:

- `illustrative: true`
- `included_by_default: false`
- `may_satisfy_evidence: false`

Copy a useful pattern into a draft only after replacing every illustrative value and attaching project-specific evidence.
